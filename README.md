# 🎉 Página de Aniversário da Aline 🎉

## 💕 Sobre o Projeto

Esta é uma página especial criada para celebrar o aniversário da Aline no dia 10/08! É uma homenagem romântica e interativa, cheia de amor e carinho.

## ✨ Recursos da Página

### 🎂 Funcionalidades Principais:
- **Galeria de Fotos Interativa**: Clique nas fotos para ver mensagens especiais
- **Cartões de Mensagem**: Cartões que giram ao clicar, revelando mensagens românticas
- **Botão de Surpresa**: Cria uma explosão de corações na tela
- **Corações Flutuantes**: Animações de fundo com corações
- **Efeitos de Clique**: Corações aparecem onde você clica na página
- **Mensagens Aleatórias**: Mensagens românticas aparecem periodicamente
- **Design Responsivo**: Funciona em celular, tablet e desktop

### 🎨 Elementos Visuais:
- Gradientes românticos em tons de rosa
- Animações suaves de corações flutuantes
- Efeitos de hover nas fotos e botões
- Tipografia elegante com fontes Google Fonts
- Modal para exibir mensagens especiais

### ⌨️ Atalhos do Teclado:
- **H**: Criar corações aleatórios
- **B**: Explosão de corações
- **ESC**: Fechar modal

## 🖼️ Como Adicionar as Fotos

1. Coloque suas fotos na pasta `fotos/`
2. Nomeie as fotos como:
   - `foto1.jpg`
   - `foto2.jpg`
   - `foto3.jpg`
   - `foto4.jpg`

**Dica**: Use fotos com boa qualidade e de preferência no formato 3:2 ou 4:3 para melhor visualização.

## 🚀 Como Usar

1. **Abrir a página**: Abra o arquivo `index.html` no navegador
2. **Interagir**: Clique nas fotos, cartões e botões
3. **Explorar**: Use os atalhos do teclado para mais efeitos
4. **Personalizar**: Edite as mensagens no arquivo `script.js`

## 💝 Personalizações Possíveis

### 📝 Alterar Mensagens:
- Edite o objeto `photoMessages` no `script.js` para personalizar as mensagens das fotos
- Modifique o array `romanticMessages` para trocar as mensagens aleatórias
- Altere a `specialMessage` na função `showSpecialMessage()`

### 🎨 Mudar Cores:
- Edite as variáveis de cor no `style.css`
- Personalize os gradientes de fundo
- Altere as cores dos corações e elementos

### 🔊 Adicionar Som:
- Adicione um arquivo de áudio na pasta do projeto
- Descomente e edite a função `playBirthdaySound()` no `script.js`
